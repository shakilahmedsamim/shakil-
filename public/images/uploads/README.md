# Image Uploads — Instructions (বাংলা + English)

এই ফোল্ডারে তোমার নিজের ছবি আপলোড করবে GitHub থেকে সরাসরি, কোড না ছুঁয়ে।

## কিভাবে আপলোড করবে (Step by step)

1. GitHub-এ রিপোতে যাও: `shakilahmedsamim/shakil-`
2. উপরের branch dropdown থেকে branch সিলেক্ট করো: `claude/ads-agency-marketing-site-wbvq7r`
3. এই ফোল্ডারে ঢোকো: `public/images/uploads/`
4. **Add file → Upload files** বাটনে ক্লিক করো
5. তোমার ছবি ড্র্যাগ করে ছাড়ো বা সিলেক্ট করো
6. নিচে **Commit changes** বাটনে ক্লিক করে সরাসরি ওই branch-এ কমিট করো (নতুন branch বানানোর দরকার নেই)
7. আপলোড হয়ে গেলে আমাকে বলবে কোন ফাইলের নাম দিয়েছো আর কোন জায়গায় (হোম পেজের হিরো, About পেজের ফটো, কোন case study ইত্যাদি) সেটা বসাতে হবে — আমি কোডে বসিয়ে দেবো।

## ফাইলের নাম যেভাবে দেবে (Naming rules)

- শুধু ছোট হাতের অক্ষর, সংখ্যা, আর হাইফেন (`-`) ব্যবহার করো। স্পেস বা বাংলা অক্ষর ব্যবহার করবে না।
- এক্সটেনশন: `.jpg`, `.jpeg`, `.png`, বা `.webp`
- নামটা যেন বোঝা যায় ছবিটা কীসের জন্য, যেমন:
  - `about-founder.jpg` — About পেজের ফাউন্ডার/তোমার ছবি
  - `google-ads-management-hero.jpg` — Google Ads Management পেজের হিরো ছবি
  - `case-study-hvac-before.jpg` / `case-study-hvac-after.jpg` — কোনো নির্দিষ্ট case study-র আগে/পরের ছবি
  - `client-logo-1.png`, `client-logo-2.png` — ক্লায়েন্ট বা পার্টনার লোগো
